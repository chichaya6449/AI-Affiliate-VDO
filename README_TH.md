# คู่มือใช้ Gem โกดังทุบราคา 10S

แพ็กเกจนี้เป็นคำสั่งสำหรับ Gemini Gem ที่วิเคราะห์ภาพสินค้าเครื่องใช้ในบ้าน แล้วสร้างคำสั่ง Google Flow พร้อมบทพูดและแคปชั่น Facebook/Shopee โดย Gem ไม่ได้สร้างวิดีโอหรือควบคุม Flow เอง

## ไฟล์หลัก

- `Warehouse_Affiliate_GEM_Instructions_10S.txt` — เนื้อหาสำหรับช่อง Instructions ของ Gem
- `tests/fixtures/behavior-cases.md` — กรณีตัวอย่างสำหรับตรวจพฤติกรรม

## สร้าง Gem

1. เปิดหน้าสร้าง Gem ใน Gemini
2. ตั้งชื่อ `โกดังทุบราคา 10S`
3. คัดลอกไฟล์ Instructions ทั้งหมดไปวาง
4. บันทึก แล้วเริ่มแชตใหม่สำหรับสินค้าแต่ละชิ้น

คำอธิบาย Gem ที่แนะนำ: `สร้าง Flow prompts รีวิวสินค้า 10 วินาทีจากภาพ 1–5 ภาพ พร้อมเสียงผู้ชายและแคปชั่น Facebook/Shopee`

## ข้อมูลที่ใช้ต่อสินค้าหนึ่งชิ้น

- แนบภาพ 1–5 ภาพ ภาพเดียวใช้ได้หากเห็นสินค้าและรายละเอียดสำคัญชัดเจน
- ภาพมุมอื่นเป็นข้อมูลเสริม ไม่ได้บังคับ
- ภาพราคา โปรโมชั่น หรือหน้าร้านใช้เป็นข้อมูลได้ แต่ Gem จะสั่งไม่ให้นำภาพเหล่านี้ไปเป็นวัตถุดิบภาพใน Flow
- ระบุชื่อสินค้า จุดขาย ราคา โปรโมชั่น การสาธิต หรือ Hook เท่าที่มี
- หากไม่ได้ระบุคนเต็มตัว ค่าเริ่มต้นคือมือผู้ชาย 1–2 มือจากผู้ชายคนเดียว

ตัวอย่างข้อมูลที่ส่งพร้อมภาพ:

```text
ชื่อสินค้าและรุ่น:
จุดขายที่ต้องการเน้น:
การใช้งานหรือท่าทางที่ต้องการสาธิต:
ต้องการผู้ชายเต็มตัวหรือไม่:
Hook ที่ต้องการ:
ราคาและโปรโมชั่น:
เงื่อนไขโปรโมชั่น:
ลิงก์สำหรับ Facebook ถ้ามี:
```

## วิธีทำงาน

เมื่อภาพและข้อมูลระบุสินค้าได้ Gem จะสร้างผลลัพธ์ทันทีโดยไม่ส่งใบยืนยันและไม่ต้องพิมพ์คำว่า `ยืนยัน` ผลลัพธ์มี 4 กล่องที่มีปุ่มคัดลอก:

1. FLOW IMAGE PROMPT
2. FLOW VIDEO PROMPT — 10 SECONDS + THAI VOICEOVER
3. FACEBOOK PAGE CAPTION + HASHTAGS
4. SHOPEE VIDEO CAPTION + HASHTAGS พร้อมจำนวนอักขระ

Gem จะถามกลับเพียงหนึ่งคำถามเมื่อมีปัญหาที่ทำงานต่อไม่ได้จริง เช่น มีหลายสินค้าแต่ไม่ทราบว่าจะเลือกชิ้นใด หรือราคาสองแหล่งขัดแย้งและผู้ใช้ต้องการกล่าวราคา

ข้อมูลหรือคำสั่งเพิ่มเติมจากผู้ใช้จะถูกนำไปใช้ทันทีหากไม่ขัดนโยบายของ Flow และไม่ทำให้ระบุตัวสินค้าผิด ไม่ต้องผ่านรอบยืนยันใหม่

## รูปแบบภาพเริ่มต้น

- ภาพแนวตั้งแบบกล้องมือถือ POV ในโกดังไทยแนว Clearance ที่สะอาด เป็นระเบียบ และแสงธรรมชาติสมจริง
- ฉากหลังเป็นชั้นหรือกองสินค้าชนิดเดียวกัน หรือบรรจุภัณฑ์จริงสีสันสดใส ไม่มีลังสีน้ำตาลทึบ
- ล็อกรูปร่าง สี วัสดุ ลาย โลโก้ สัดส่วน และส่วนประกอบตามภาพอ้างอิง
- ใช้มือผู้ชายที่สมจริง หากมีสองมือต้องเป็นมือซ้ายหนึ่งและมือขวาหนึ่งจากคนเดียวกัน
- เพิ่มผู้ชายเต็มตัวเฉพาะเมื่อผู้ใช้ระบุว่าต้องการ
- มี Hook ภาษาไทยที่เด่นและอ่านง่ายหนึ่งข้อความบริเวณด้านบน
- ไม่มีป้ายราคา ป้ายลดราคา เปอร์เซ็นต์ หรือตัวเลขที่สร้างใหม่เป็นป้ายฉากหลัง และ Hook ห้ามเป็นราคาหรือส่วนลด
- Hook เป็นข้อความสร้างใหม่เพียงรายการเดียว แต่ต้องรักษาตัวอักษรและตัวเลขจริงที่พิมพ์อยู่บนสินค้าและบรรจุภัณฑ์เดิม

## บทพูดและวิดีโอ

วิดีโอใช้ `Gemini Omni Flash 1.1`, `Frames to Video: First`, อัตราส่วน `9:16`, ระยะเวลา `10 วินาที` และเปิด `Audio`

วิดีโอต้องเริ่มตรงจากเฟรมแรก ล็อกตัวตนสินค้า ห้ามเปลี่ยนรุ่น สี รูปร่าง โลโก้ หรือสลับสินค้า ใช้การเคลื่อนไหวของมือและกล้องเพียงเล็กน้อยแต่ต้องนำเสนอสินค้าอย่างมีจุดหมาย ไม่ชืดหรือแข็งทื่อ และห้ามสร้างข้อความใหม่เพิ่มจากภาพเริ่มต้น

ค่าเริ่มต้นใช้เสียงผู้ชายไทย น้ำเสียงขายมีพลัง เป็นธรรมชาติ และลงท้าย `ครับ` หากผู้ใช้สั่งเปลี่ยนเพศภายหลัง Gem จะเปลี่ยนมือ คนสาธิต เสียง และคำลงท้ายให้ตรงกันทันที บทพูดเป้าหมาย 150–170 อักขระและต้องพูดครบใน 10 วินาที ใช้โครงสร้าง:

`ปัญหา → ความไม่สะดวกหรือความต้องการ → สินค้าเป็นทางออก → จุดขาย → โปรโมชั่นที่ยืนยันได้ → กดตะกร้า`

CTA เริ่มต้นคือ `กดตะกร้าด้านล่างได้เลยครับ` หากผู้ใช้เปลี่ยนเพศผู้บรรยาย ให้เปลี่ยนคำลงท้ายให้ตรงกับเสียงที่เลือก

## นำไปใช้ใน Flow

1. คัดลอก FLOW IMAGE PROMPT และแนบเฉพาะภาพสินค้าที่ Gem ระบุ ห้ามแนบภาพราคาและภาพโปรโมชั่นเป็นภาพอ้างอิง
2. สร้างภาพแล้วตรวจสินค้า สัดส่วน สี โลโก้ มือ และ Hook ก่อนใช้เครดิตสร้างวิดีโอ
3. ใช้ภาพที่ผ่านเป็น Starting image และตั้งค่าโมเดล อัตราส่วน ระยะเวลา และ Audio ตามด้านบน
4. คัดลอก FLOW VIDEO PROMPT — 10 SECONDS + THAI VOICEOVER ไปสร้างวิดีโอ
5. ดูวิดีโอให้จบก่อนดาวน์โหลด ตรวจสินค้า มือ การเคลื่อนไหว ข้อความเดิม เสียง และ CTA

## เมื่อต้องการแก้

ส่งปัญหาหรือข้อมูลใหม่ให้ Gem โดยตรง เช่น `มือเกิน`, `สินค้าเปลี่ยนสี`, `Hook สะกดผิด`, `เปลี่ยนเป็นผู้ชายสาธิตเต็มตัว` หรือ `ใช้ราคาใหม่` Gem จะนำคำสั่งล่าสุดไปแก้ครบทั้ง 4 กล่องทันที หากคำสั่งไม่ขัดนโยบายของ Flow

## เทคนิคประหยัดเครดิต

- ตรวจภาพเริ่มต้นให้ถูกต้องก่อนสร้างวิดีโอ
- ใช้การสาธิตที่ชัดเจนหนึ่งอย่างต่อคลิป
- เริ่มแชตใหม่เมื่อเปลี่ยนสินค้า เพื่อไม่ให้รุ่นหรือโปรโมชั่นปะปน
- บันทึกจุดที่ผิดแล้วสั่งแก้เฉพาะจุดก่อนกดสร้างใหม่
